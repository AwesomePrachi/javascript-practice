# Operators

Practice examples covering JavaScript operators and expressions.

## Topics

- Assignment operators
- Arithmetic operators
- Comparison operators
- Logical operators
- Unary operators
- Update operators
- Ternary operator
- `typeof`
- `instanceof`

## Files

- `01-assignment-operators.js` — Assignment and compound assignment
- `02-arithmetic-operators.js` — Arithmetic operations and string concatenation
- `03-comparison-operators.js` — Equality and relational comparisons
- `04-logical-operators.js` — Logical AND, OR, and NOT
- `05-unary-and-update-operators.js` — Unary operators and increment/decrement
- `06-ternary-operator.js` — Conditional expressions
- `07-typeof.js` — Type checking with `typeof`
- `08-instanceof.js` — Instance checking with `instanceof`
