# Loops

Practice examples covering JavaScript loops, iteration control, nested loops, and loop-based problem solving.

## Topics

- `for` loop
- `while` loop
- `do...while` loop
- `break`
- `continue`
- Nested loops
- Number patterns
- Number and digit problems

## Files

- `01-for-loop.js` — `for` loop syntax and basic iteration
- `02-while-loop.js` — `while` loop syntax and basic iteration
- `03-do-while-loop.js` — `do...while` loop and its execution behavior
- `04-break-and-continue.js` — Controlling loop execution
- `05-loop-practice.js` — Basic loop-based problem solving
- `06-nested-loops-and-patterns.js` — Nested loops and pattern generation
- `07-number-and-digit-problems.js` — Loop-based number and digit problems
