# Show Message

A beginner JavaScript DOM project that displays a message when the user clicks a button.

## Features

- Displays a welcome message on button click
- Uses a live region so assistive technology can announce the updated message
- Keeps HTML, CSS, and JavaScript in separate files

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in a web browser.

## Concepts Practiced

- Selecting elements with `document.querySelector()`
- Handling clicks with `addEventListener()`
- Updating page content with `textContent`
