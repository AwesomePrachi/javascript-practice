# Show or Hide Password

A beginner JavaScript DOM project that lets users toggle password visibility.

## Features

- Show a password as plain text
- Hide the password again
- Update the button label to describe the next action
- Responsive dark-themed interface
- Reduced-motion support

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in a web browser.

## Concepts Practiced

- Selecting elements with `document.querySelector()`
- Handling clicks with `addEventListener()`
- Reading and updating the input's `type` property
- Updating text with `textContent`
- Using a conditional expression

## Note

This is a learning demo. It only toggles password visibility; it does not save, transmit, authenticate, or verify passwords.
