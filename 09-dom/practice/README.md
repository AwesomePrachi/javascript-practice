# JavaScript DOM Practice

A collection of beginner-friendly projects for practicing JavaScript DOM selection, event handling, and dynamic page updates.

## Projects

| Project | Description | Concepts |
|---|---|---|
| [Show Message](./practice/01-show-message/) | Displays a message when a button is clicked. | `querySelector()`, `addEventListener()`, `textContent` |
| [Simple Counter](./practice/02-simple-counter/) | Increases, decreases, and resets a displayed count. | DOM selection, click events, state with `let`, `textContent` |

## Run Locally

Open a project's `index.html` file in a browser.

## Learning Goal

Practice connecting HTML, CSS, and JavaScript to create interactive browser experiences.
