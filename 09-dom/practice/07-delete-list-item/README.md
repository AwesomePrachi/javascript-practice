# Delete a List Item

A beginner-friendly JavaScript DOM project that lets users remove individual tasks from a list.

## Features

- Delete individual list items
- Animate task removal
- Update the item count automatically
- Display an empty-state message when all tasks are removed
- Responsive dark-themed interface
- Reduced-motion styling

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in a web browser.

## Concepts Practiced

- Selecting multiple elements with `document.querySelectorAll()`
- Handling click events
- Event delegation
- Finding an ancestor with `closest()`
- Removing elements with `remove()`
- Updating the DOM and item counts
- Using `classList` to trigger CSS animations
- Handling the `animationend` event

## Note

The initial tasks are defined in the HTML. Deleted tasks are not saved, so refreshing the page restores the original list.
