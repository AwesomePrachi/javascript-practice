# Star Rating – DOM Practice

An interactive five-star rating component built with HTML, CSS, and vanilla JavaScript.

## Features

- Select a rating from 1 to 5 stars
- Highlight all stars up to the selected rating
- Display a dynamic message based on the selected rating
- Show hover and selection animations
- Responsive layout for smaller screens
- Keyboard-operable star buttons
- Reduced-motion support for users who prefer less animation

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## Concepts Practiced

- DOM selection using `querySelector()` and `querySelectorAll()`
- Event handling with `addEventListener()`
- Reading `data-*` attributes with `dataset`
- Type conversion using `Number()`
- Iterating with `forEach()`
- Updating CSS classes with `classList`
- Updating text with `textContent`
- Managing UI state with a variable
- Responsive styling and basic accessibility

## How to Run

1. Clone or download the repository.
2. Open the `09-dom/practice/14-star-rating/` folder.
3. Open `index.html` in a web browser.

No dependencies or build tools are required.

## Limitations

- The selected rating resets when the page is refreshed.
- Ratings are not submitted to a backend or database.
- This is a frontend practice project, not a complete feedback submission system.

## Purpose

Created to practice DOM manipulation, event handling, UI state updates, and accessible interactive controls using vanilla JavaScript.
