# Simple Counter

A small interactive counter built with HTML, CSS, and vanilla JavaScript.

## Features

- Increase the count
- Decrease the count
- Reset the count to zero
- Update the displayed value after each action

The counter can go below zero; this is intentional in the current version.

## Technologies

- HTML5
- CSS3
- JavaScript

## Run Locally

Open `index.html` in a web browser.

## Concepts Practiced

- Selecting DOM elements with `document.querySelector()`
- Handling button clicks with `addEventListener()`
- Managing changing state with `let`
- Updating displayed content with `textContent`
- Reusing an `updateCountDisplay()` function
