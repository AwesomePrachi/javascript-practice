# Personalized Greeting

A beginner-friendly JavaScript DOM project that displays a personalized greeting based on the user's input.

## Features

- Accepts a name through a text input
- Displays a personalized greeting
- Shows a validation message when the input is empty
- Supports button clicks and Enter-key submission
- Uses CSS classes for success and error states
- Includes a simple entrance animation
- Respects reduced-motion preferences

## Technologies

- HTML5
- CSS3
- JavaScript (DOM manipulation and events)

## Run Locally

Open `index.html` in a web browser.

## Concepts Practiced

- `document.querySelector()`
- `addEventListener()`
- Form submission and `preventDefault()`
- Reading input with `.value`
- Removing surrounding whitespace with `.trim()`
- Conditional logic
- Updating text with `textContent`
- Managing CSS classes with `classList`
- Basic input validation

## Learning Goal

Practice collecting user input, validating it, and updating the DOM in response to user interaction.
