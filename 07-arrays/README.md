# Arrays

Practice examples covering JavaScript arrays, array methods, iteration, transformation, filtering, aggregation, searching, destructuring, and spread syntax.

## Topics

- Creating arrays
- Accessing and modifying array elements
- Array indexing
- Array length
- Array methods
- Mutating and non-mutating methods
- `forEach()`
- `map()`
- `filter()`
- `reduce()`
- `find()`
- `some()`
- `every()`
- Array destructuring
- Spread syntax
- Shallow copying
- Array practice problems

## Files

- `01-array-basics.js` — Creating, accessing, modifying, and measuring arrays
- `02-array-methods.js` — Common array methods and mutation behavior
- `03-for-each-and-map.js` — Iteration and array transformation
- `04-filter-and-reduce.js` — Filtering elements and reducing arrays to a value
- `05-find-some-and-every.js` — Searching and testing array elements
- `06-destructuring-and-spread.js` — Array destructuring, spread syntax, and shallow copies
- `07-array-practice.js` — Practical array exercises
