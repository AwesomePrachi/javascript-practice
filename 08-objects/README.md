# Objects

Practice examples covering JavaScript objects, property access, nested objects, destructuring, object iteration, copying, cloning, optional chaining, and computed properties.

## Topics

- Creating objects
- Object properties
- Dot notation
- Bracket notation
- Dynamic property access
- Nested objects
- Object destructuring
- `for...in`
- `Object.keys()`
- `Object.entries()`
- Object spread syntax
- `Object.assign()`
- Shallow copying
- Deep cloning
- Optional chaining
- Computed properties
- Object practice problems

## Files

- `01-object-basics.js` — Creating objects and working with basic properties
- `02-property-access-and-computed-properties.js` — Dot notation, bracket notation, dynamic keys, and computed properties
- `03-nested-objects-and-destructuring.js` — Nested objects, deep property access, and object destructuring
- `04-object-iteration-and-static-methods.js` — `for...in`, `Object.keys()`, and `Object.entries()`
- `05-copying-and-cloning-objects.js` — Object spread, `Object.assign()`, shallow copies, and deep cloning
- `06-optional-chaining.js` — Safely accessing potentially missing properties
- `07-object-practice.js` — Practical object exercises
