# Data Types

Practice examples covering JavaScript data types, dynamic typing, type behavior, coercion, and truthy/falsy values.

## Topics

- Primitive values
- Objects
- Dynamic typing
- `typeof`
- `null` and `undefined`
- `NaN`
- `BigInt`
- Type coercion
- `==` vs `===`
- Truthy and falsy values

## Files

- `01-primitives-and-objects.js` — Primitive values, objects, arrays, and functions
- `02-dynamic-typing.js` — Dynamic type behavior
- `03-typeof-quirks.js` — `typeof`, `NaN`, floating-point precision, and safe integers
- `04-type-coercion.js` — Implicit conversion and equality comparisons
- `05-truthy-and-falsy.js` — Boolean coercion and truthy/falsy values
