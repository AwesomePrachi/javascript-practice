# Functions

Practice examples covering JavaScript functions, parameters, return values, higher-order functions, closures, scope, IIFEs, and hoisting.

## Topics

- Function declarations
- Function expressions
- Arrow functions
- Parameters and arguments
- Default parameters
- Rest parameters
- Return values
- First-class functions
- Higher-order functions
- Pure and impure functions
- Closures
- Lexical scope
- IIFE
- Function hoisting

- `02-function-expressions-and-arrow-functions.js` — Function expressions and arrow functions
