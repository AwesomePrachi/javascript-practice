# Control Flow

Practice examples covering JavaScript conditional statements and control flow.

## Topics

- `if`
- `if...else`
- `else if`
- `switch`
- `break`
- Switch fall-through
- Early return

## Files

- `01-if-else.js` — `if`, `if...else`, and `else if`
- `02-switch.js` — `switch`, `case`, `break`, `default`, and fall-through
- `03-early-return.js` — Using `return` to exit a function early
- `04-grade-calculator.js` — Grade calculation using conditional logic
- `05-rock-paper-scissors.js` — Rock-paper-scissors game logic using conditional statements
